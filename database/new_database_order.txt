#
# ★ 순서는 파일 이름 정렬이 아니라 이 목록이다. FK · 뷰 · 함수가 가리키는 객체를 만드는 파일이
#   먼저 온다(2026-09-30 BL-021 · 임시 PostgreSQL 17 빈 DB 에서 확인). 스키마 파일을 더하면
#   여기에도 넣는다 — `tests/scripts/test_new_database_order.py` 가 빠진 파일과 순서를 잰다.
# ★ schema/ 파일만 담는다. 각 파일이 새 DB 의 최종 정의다 — 2026-09-30 BL-021 보완으로 전에 목록
#   끝에서 따로 돌던 migrations/ 8개의 효과를 해당 schema 파일에 담고 목록에서 뺐다. migrations/ 는
#   이미 쓰는 DB 를 갱신할 때 한 파일씩 쓴다(`database/README.md` §2).
# 🔴 seed/ 는 넣지 않는다 — 데이터는 사용자가 확인하고 직접 넣는다(`database/seed/README.md`).
